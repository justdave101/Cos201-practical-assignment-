# COS 201 — Week 3 Practical

Programs on Variables, Data Types, Expressions and Input/Output.

## Programs
- `SimpleCalculator.java` — reads two numbers and prints their sum, difference, product and quotient.
- `AverageCalculator.java` — reads three scores and prints the total and average.
- `ItemCost.java` — reads an item name, unit price and quantity, then prints the total cost.

## Requirements
Java Development Kit (JDK) 8 or later.

## How to compile
```
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

## How to run
```
java SimpleCalculator
java AverageCalculator
java ItemCost
```

## Sample run (ItemCost)
```
Enter item name: Notebook
Enter unit price: 250.50
Enter quantity: 4
Item: Notebook
Unit price: 250.5
Quantity: 4
Total cost: 1002.00
```
